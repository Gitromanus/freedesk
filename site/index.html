Как это работает

Три шага до удалённого рабочего стола.

1

Скачайте и запустите

Скачайте FreeDesk.exe. Приложение покажет ваш 9-значный ID. Никакой регистрации.

2

Передайте ID

Сообщите свой ID или введите чужой в поле «Подключиться».

3

Работайте

Нажмите «Подключиться» — через пару секунд откроется окно с удалённым экраном.

Вопросы и ответы

FreeDesk действительно бесплатный?

Да, полностью бесплатный. Никаких подписок, ограничений по времени или платных функций.

Нужна ли регистрация?

Нет. При первом запуске приложение автоматически получает 9-значный ID. Никаких email и паролей.

Как работает подключение?

Устройства соединяются напрямую через WebRTC. Сервер только помогает им найти друг друга.

Безопасно ли это?

Да. TLS, токены 256 бит, сессии с автопротуханием. Сервер не видит экран и ввод.

Почему Windows предупреждает?

FreeDesk не подписан цифровой подписью. Нажмите «Подробнее» → «Выполнить в любом случае».

Работает ли через интернет?

Да, из любой точки мира. Не нужна локальная сеть или VPN.

Есть ли версия для macOS/Linux?

Пока только Windows. macOS и Linux — в планах.
